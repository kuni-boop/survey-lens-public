# Survey Lens

アンケートCSVの集計・可視化、課題と改善施策の整理、報告出力を行うWebアプリです。生成AIの社内活用状況、研修アンケート、従業員調査の3種類に対応しています。

## Macで使う

1. このブランチの `SurveyLens-2026-10-24.zip` をダウンロードします。
2. ZIPをダブルクリックして展開します。
3. 展開したフォルダ内の `index.html` をブラウザで開きます。
4. 「架空サンプルで試す」→「この対応で集計する」で操作を確認できます。

追加インストールやターミナル操作は不要です。HTML単体でも動作します。

## データの扱い

公開対象はアプリと架空サンプルだけです。実データ・個人情報・認証情報は含みません。
読み込んだCSVはブラウザのメモリ内で処理し、アプリから外部サーバーやAPIへ送信・永続保存しません。CSV・PDFの出力は利用者の明示操作で行います。
実際のアンケートCSVをGitHubへ追加しないでください。GitHub Pagesを利用する場合、ページへのアクセス情報の扱いはGitHubの方針に従います。

## 品質確認と制約

2026-10-24の品質検証で4不具合を修正しました。65テストが成功し、6つの架空CSV・27対象・162分布を独立集計と照合しています。
利用割合はその設問の有効回答者数が分母です。全社員・全アカウントに対する利用率は推定しません。施策は限定的なルールベースの候補で、生成AIによる文章分析や効果の実証ではありません。
Mac実機・Safari・Firefox、表計算ソフトでのCSV実行、最大件数での性能等は未検証です。詳細な検証ログや内部パスを含む資料はこの公開配布物に含めていません。

このブランチはGitHub Pagesで配信できる静的ファイル構成です。サイトの有効化はリポジトリのSettings → Pagesで、Deploy from a branch、gh-pages、/ (root) を選択します。
